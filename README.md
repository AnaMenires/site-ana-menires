# Ana Menires

Site pessoal de Ana Menires: marketing, tecnologia e estratégia.

Página estática (HTML, CSS e JavaScript em um único `index.html`), sem build. Imagens em `assets/img/` (WebP) e vídeos em `assets/video/`.

## Publicar no GitHub Pages

1. Em **Settings → Pages**, escolha **Deploy from a branch**.
2. Selecione a branch `main` e a pasta `/ (root)`.
3. O site fica em `https://<seu-usuario>.github.io/<nome-do-repositorio>/`.

Para ver localmente: `python3 -m http.server` nesta pasta e abra `http://localhost:8000`.
